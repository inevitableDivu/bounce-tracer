## Git Commit Format Rule
AI agents must format all git commit messages using the following pattern:
`<emoji><action_type>: <message>`

### Format Specification:
- `<emoji>`: An appropriate emoji representing the change type (e.g., ✨, 🐛, 📝, ♻️, 🎨, ⚡️, 🧪, 🔧).
- `<action_type>`: The type of commit in lowercase (e.g., `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`).
- `: `: A colon followed by a space.
- `<message>`: A concise description of the changes in imperative mood (e.g., "add user authentication modal").

### Examples:
- `✨feat: add user login component`
- `🐛fix: resolve null pointer in user payload`
- `📝docs: update API documentation`
- `♻️refactor: simplify state management logic`
- `🔧chore: update npm dependencies`
